# Revela para macOS con Homebrew

```sh
brew install --cask fmesasc/revela/revela
```

[Revela](https://revelaslides.com) es un editor de presentaciones con 3D, animaciones, votaciones del público y compatible
con PowerPoint. La aplicación se actualiza sola. Más formas de instalarla: https://revelaslides.com/download

El cask sale de [fmesasc/revela](https://github.com/fmesasc/revela) (`desktop/homebrew/`).
